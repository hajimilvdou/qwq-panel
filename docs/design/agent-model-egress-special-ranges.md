# 模型端点 IPv6 特殊地址范围

默认模型出站策略补充0000::/8保留范围、64:ff9b:1::/48本地NAT64、100::/64丢弃范围及2001::/32 Teredo。已有64:ff9b::/96与2002::/16保留，不重复添加；IPv4及其他IPv6特殊范围不变。

判断继续在DNS解析后的实际拨号地址执行。IPv4映射地址先Unmap，因此公网IPv4映射可用，私网映射仍拒绝；去掉zone不改变地址权限。管理员显式prefix/addr:port例外、默认禁止重定向/环境代理及固定错误文案沿用原链路。

Linux真实RED确认7个新增IPv6特殊地址样本被默认放行；原NAT64/6to4/私网映射拒绝及公网正对照保留。最终定向、三包普通/单包race、静态/lint/build及2Go严格格式和Root P0/P1/P2复核通过，全部旧失败保留；不以地址分类测试替代实际CLI/真实模型/双VPS终验。
