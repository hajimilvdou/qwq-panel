# 监控采样的墙钟与单调间隔

当前 sampler 在宿主时间不推进时直接返回，保留未来的 previous；NTP 回拨后新采样在追上旧墙钟前都被拒绝。速率还用宿主墙钟差作为分母，时间向前调整会把真实短时流量稀释成接近零。

复用现有 Source、计数派生与有限环。失效/重复时间戳继续保留明确错误与断点，但有效返回的 current 必须成为下一次比较的基线；真正无效时间/读取失败不污染基线。速率用进程单调采样间隔，公开采样时间保持真实宿主时间。基线重置时同步清理间隔状态和聚合边界，不能混合跨回拨计数或伪造连续历史。

首轮真实时序/计数 RED 已确认三个失败：回拨后基线卡死、重复时间戳使用旧计数、短时读取的一小时墙钟跳变稀释速率。现在共用 resetHistoryLocked：只有真正回拨才清除未来历史并递增 epoch，重复时间戳保留已有历史但重定计数/单调基线与聚合边界，仍明确报告一次断点；随后立即采样。进程单调时间在 Source.Read 返回后取值，reset/configure 同步清空时间基线；derive 的所有调用显式提供实际间隔，原 widget 单位契约用受控一秒单调时钟保留。多挂载点/接口过滤/历史 metric 及 UI 曲线属于随后 PLG06，整体监控与长时验收保持未完成。
