# Core 工作目录回收

P1-PLG-01：完成明确 attempt 后，删除已空的 owner 目录；owner 仍有其他 attempt 时保留。崩溃导致 attempt 已消失的重试仍检查并回收空 owner。复用原私有根、目录权限、owner 校验、插件锁和目录 fsync。

开机恢复按 32 项分批读取，owner/attempt 复用同一个读取与取消边界。先遍历校验所有 owner、规范 uint32 attempt 和真实私有目录，再重新遍历删除；不再因历史残留超过 1024 项拒绝启动，也不把完整目录清单放进内存。

拒绝坏 owner/attempt/链接的安全行为保持；验证失败前不删除先前批次。清理过程不改当前/上一代配置指针，不增加进程启停或秘密读取。Linux 使用真实私有树验证空目录、多个 attempt、历史残留、跨批次坏输入和幂等重试，再运行 Core 受影响包普通/race/静态检查与构建。
