# 初始化与首次密码链接预检

状态：已实施，2026-11-20 受影响范围验证通过；对应 P1-CORE-02。

无效安装链接、已用或过期的首次密码链接以前会进入 Argon2id 队列，与正常登录争用全进程的两个哈希槽。管理员后来设置密码时，未使用的旧链接也可能再次覆盖密码。Linux 回归已经在未改生产代码时复现这些问题。

现在两类入口共用廉价的用途、SHA-256、恒时比较、已用和到期查询。安装关闭状态仍先检查；规范化用户名和显示名以后，先确认 token，再在写事务外计算密码哈希。token 规则在提交事务中再次执行，哈希期间替换或失效的链接不能提交。

首次密码兑换另外在哈希前和写事务中核验当前用户未禁用、尚无密码。提交只插入第一条密码凭据，不能更新已有密码。管理员设置密码时，在同一事务中撤销该用户未使用的 enrollment 链接；新链接和重置流程共用按用途及 user_id 精确清理的函数，不影响其他用户或安装 token。

节流复用已有 LoginThrottle 的 4096 条目上限和原子 Attempt：账户键使用目的与 token 摘要，与用户名及 password/MFA 键分开；IP 喷洒预算共享。HTTP 兑换将网关已经确定的 ClientIP 传入私有实现，公开 RedeemEnrollmentToken 三参数签名继续可用。成功退还 pair 计数，IP 计数依原规则衰减。

HTTP 语义保持：安装已关闭 409；错误、已用或过期链接 401；禁用用户 403；有效链接的密码策略错误 400；节流 429 并携带 Retry-After；成功仍 201 和原会话 cookie。

验证覆盖占满真实哈希槽时失效 token 立即拒绝、有效 token 仍等待、管理员设密码后的旧链接及其他用户隔离、公共入口节流、明确跨过哈希后发生的 token 替换/到期/禁用/密码出现及安装状态改变。哈希握手夹具必须到达实际计算边界，避免把哈希前的拒绝算作事务重验。

实现不新增依赖、后台 goroutine、缓存或数据库迁移，不修改原哈希参数、登录节流参数或节点 mTLS 入网协议。完整验证结果收取后再更新本状态及主施工表。

Linux 验证：真实失效 token/哈希边界/HTTP 回归通过，identity/authz/API/controller/cmd 五包普通、race、vet、staticcheck、仓库 lint 与 Controller 构建通过。7源SHA及6Go格式成员经完整校验取回；旧RED失败保留。完整证据在 `.cache/sdd/reports/ROOT-identity-token-prechecks-20261120.md`。Root 按 HANDOFF §11.4 独立复核，本范围 P0/P1/P2 无未处理项。
