TCP Brutal + Brutal Custom 端口透明接管（按 TCP 订阅独立开启 + 手调超发倍率）

        
在母机网络被恶意抢占带宽且无法使用 UDP 的场景下，通过纯 Go 透明 TCP 接管层为选定的单个 TCP 入站端口设置 TCP_CONGESTION=brutal 与 TCP_BRUTAL_PARAMS(23301)；未选中的其他 TCP 订阅保持原端口直连。支持手动调节超发包倍率（原始默认 125%，范围 100%–250%）。
