ACME 自动证书申请向导

支持免 DNS Token 的 HTTP-01（通过内置 web.ingress 80 端口验证）与联动 domain.dns 的 DNS-01（支持泛域名）。

无需配置 Cloudflare/阿里云 API Token：只需将域名 A/AAAA 记录解析到本机公网 IP，且已安装启用 web.ingress 监听 80 端口即可签发。

手动导入外部 PEM 证书链与私钥

私钥提交后将由宿主直接提取并加密保存，校验链与私钥配对、SAN 与信任级别后写入新代。

生成受控自签名测试证书
